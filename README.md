# party-silver-edm

You are going to build lakeflow declarative pipelines, you can find an example on how to implement under the example folder. Under the analysis folder you have the sql statement that will feed into the target tables. File names are the target table names. Create all the necessary pipeliens under a new folder called pipeline.

Follow the same naming convention for the temporary view names and target table names. 
Understand the example well. Do not use the supplied sql as is. Each driving master table should have its own flow. Reference tables can be still joined as they are small
